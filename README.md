Инструмент для автоматической проверки качества тайпа (верстки текста) в манхве.

Скрипт анализирует изображения страниц, находит текст через OCR и определяет строки, которые визуально смещены относительно центра.

---

## 🚀 Возможности

- 📖 Распознавание текста через Tesseract OCR
- 🇷🇺 Поддержка русского языка (`rus`)
- 📐 Проверка центрирования строк
- 🧠 Анализ:
  - центра текстового блока (основной метод)
  - баблов (дополнительная эвристика)
- 🔴 Подсветка проблемных строк
- 💾 Автоматическое сохранение результатов

## 📊 Как работает
- Загружает изображения из папки
- Распознаёт текст через OCR
- Группирует строки по блокам и абзацам
- Вычисляет центр текстового блока
- Сравнивает центр каждой строки с центром блока
- Дополнительно анализирует баблы
- Помечает строки с отклонением

## ⚠️ Ограничения
- OCR может ошибаться при:
- плохом качестве изображений
- нестандартных шрифтах
- Детекция баблов не всегда точная
- Очень короткие строки игнорируются
